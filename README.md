# data-analytics-projects
A collection of my data analytics projects showcasing data visualization, machine learning, and insights using Excel, Python, SQL, Tableau, and Power BI.

## Projects

### 1. Superstore Sales Dashboard (Power BI)

An interactive Power BI report analysing the Superstore retail dataset (~1.92M in total sales).

**Files**
- [`Superstore Power BI.pbix`](Superstore%20Power%20BI.pbix) – the Power BI Desktop report (open in Power BI Desktop)
- [`Superstore-Power-BI.pdf`](Superstore-Power-BI.pdf) – a PDF export of the report pages for quick viewing

**What it covers**
- Sales and profit split by product category (Technology, Furniture, Office Supplies)
- Sales and customer counts by state/province and city
- Profit by product container
- Top 3 customers by sales
- Headline KPIs: total sales, total profit, average sales, total discount

**Skills:** data modelling, DAX measures, report design, KPI cards, geographic and categorical visuals.

### 2. Online E-shop Database: ER Diagram & SQL (SQL)

A relational database design for an online shop that sells music records, movies and books, delivered as a written portfolio.

**Files**
- [`SQL Script for ER Diagram.pdf`](SQL%20Script%20for%20ER%20Diagram.pdf)

**What it covers**
- An entity-relationship diagram with the entities Customers, Orders, Products Detail, Product Type, Payment Type, Delivery, Employee and Departments
- An explanation of the relationships and cardinalities between entities
- SQL DDL scripts that create the schema (primary and foreign keys)
- SQL scripts that insert sample records
- Example SQL queries and business use cases

**Skills:** database design, normalisation, ER modelling, SQL DDL/DML, analytical querying.
